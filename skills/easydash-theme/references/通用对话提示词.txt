【字段和外观，大小写照写】
新作品使用独立 id，以英文字母或数字开头，可含下划线、点、连字符，最多 128 字符，不含连续两个点。orientation 为 landscape 或 portrait。elements 放 1 至 128 个组件，按从底到顶排列。每个都写数字 x、y、width、height，原点在画布左上，尺寸为正数。可选 rotation 表示绕中心顺时针旋转的角度。颜色用 #RRGGBB 或 #AARRGGBB。
• metric 数值卡的 gaugeStyle 可取 timing 计时数字、scanline 扫描数字、sideBand 侧标卡、nameplate 铭牌卡。format 可取 number、gear（档位）或 timer（输入秒）。fontSize、labelSize、unitSize 分别控制数字、标签、单位字号。
• arcGauge 弧形表可取 segmented 分段环、minimal 细环、trackArc 赛道粗弧、blockArc 断块环。showValue 为 true 显示中心读数。startDegrees 和 sweepDegrees 分别设置起点和跨度。
• radialGauge 指针表可取 classic 机械盘、minimal 简刻盘。可设 showNeedle、majorTicks、minorTicks、showTickLabels。多指针放在 series 数组，每项写 parameter、slot、slotLabel、color。
• barGauge 条形表可取 solid 连续条、graduated 阶梯条、blockCells 方格条、dotMatrix 点阵条。layout 为 vertical 时自下往上增长。segments 控制分段，dotColumns 和 dotRows 控制点阵。
• vehicleDiagram 车辆数据图可取 outline 线框、compact 数据列表。最多四项，把 parameters、slots、slotLabels、labels、units、decimalPlaces 六个数组按相同通道顺序排齐。
• 上述五类的外观名写入组件的 gaugeStyle，省略或填 standard 可用默认外观。弧形、指针和条形表应按通道原始单位填写 min、max（max 大于 min）。
• traceChart 绘制历史曲线，series 每项写 parameter、slot、slotLabel、label、color。静态标题用 label 的 text，色块用 panel，分隔线用 line。

【数据从哪里来】
parameter 是车辆通道 ID，slot 是用户在手机上可以换绑的数据位，slotLabel 是给用户看的中文名。每个动态数据位都写清绑定。同一转速的数字、环和提示音需要一起换绑时共用 slot 和默认 parameter；想分开换绑就各用一个 slot。普通数值卡用 autoLabel、autoUnit 跟随换绑。
常用通道和原始单位：车速 speed（km/h），转速 rpm（RPM），水温 coolant_temp_std、进气温度 intake_temp_std、机油温度 oil_temp_std（均为 °C），电压 battery_voltage（V，通常一位小数），节气门 throttle_std、发动机负荷 engine_load_std（均为 %），进气歧管绝对压力 turbo_std（kPa），空气流量 maf_std（g/s），发动机运行时长 run_time_std（s）。车型支持时也可用厂家通道：档位 gear_lufi1（unit 填 ""，format 填 gear）、油温 oil_temp_lufi1（°C）、变速箱油温 gearbox_temp_cma_t2（°C）。
未列出的通道请依据我提供的 EasyDash 参数 ID。读不到的普通数值由应用显示 --，不要补 0 或绘制固定读数。只改 unit 不会换算数值。数值卡如需换算可设 valueScale、valueOffset，显示值＝原始值×系数＋偏移。将 turbo_std 标为绝对压力；相对增压需要额外的基准压力或已换算通道。报警用 alarmEnabled 和 lowThreshold、highThreshold 或 dangerThreshold，按车型或我的要求填写原始单位的阈值。
