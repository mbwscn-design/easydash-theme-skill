# EasyDash 仪表主题生成器

交付用户能打开、模拟和继续编辑的 `.easydash.json`。使用者只需要这个技能和自己的素材。以下相对路径均以含本文件的技能目录为起点，生成结果放在用户当前工程或指定的交付目录。

## 从设计到可编辑主题

1. 按目标屏幕确定布局。已有工程沿用原画布；新设计未指定尺寸时，可以从横屏 1280 × 520 开始。先决定第一眼要读到的数值，再排次要数据。参考图用来提取布局、刻度、数字、色彩与状态变化。底图可以画外框和角色，实时数字、进度和指针要用可编辑组件覆盖。
2. 查 [主题格式与通道表](references/theme-format.md) 选用实际支持的组件、参数 ID、单位和资源字段。需要起点时，复制 [无外部素材的示例清单](assets/starter.json) 到工作目录。新作品取独立的 `id`。更新旧作时，从原工程读取 `id`、已有数据位的 `slot`、多通道顺序和用户当前设置。用户只有截图且希望继承旧绑定时，请他附上原主题导出文件。两个视图若应随用户的绑定一起变化，让它们使用同一个数据位。
3. 按用途选外观。例如车速可用计时数字，电压可用带单位和一位小数的铭牌卡，转速环可选粗弧或断块。各层的几何位置由清单决定。静态预览中的模拟读数只用于演示，主题需从 `parameter` 获取实时数值。用户指定了通道或阈值就采用其配置；对车型专属数据使用已知 ID 或请用户给出通道名。避免把示例的报警转速当作适配所有车辆的设定。
4. 动效、插画和声音按实际需求加入。进度条、弧和指针可直接跟随数据；角色多帧变化、提示音的触发与冷却见格式参考。用自己的文件或用户提供的素材，将引用嵌入包内，使成品可以离线使用。用户只给了风格描述时，可优先用原生组件做出可用版本。

## 打包与检查

运行随附的 Python 3 脚本，参数传入实际绝对路径或当前工作目录下的路径。命令示例中的 `<技能目录>` 替换为本文件所在目录。Windows 可将 `python3` 换为 `py -3`。

```sh
python3 "<技能目录>/scripts/pack_theme.py" "./manifest.json" --out "./赛道主题.easydash.json"
```

有本地图片或 WAV 时，加上 `--assets "./素材"`。修订带素材的导出包时，复制原文件到工作目录，只编辑副本中的 `watchface`，再把该副本作为脚本输入，输出到新文件。这样保留已有资源、ID 和槽位。纯组件主题在缺少 Python 的环境下也可直接交付完整的 v1 清单，文件名使用 `.easydash.json`；此时如实说明尚未运行本地打包检查。

交付前核对通道单位、图层遮挡、长数值和无数据占位。能使用编辑器时，经「打开工程」加载交付文件，用模拟滑杆看低、中、高读数和动效阈值；有原工程时比对旧槽位。仅完成文件检查时说明验证范围。给用户可取用的文件、简短导入路径和实际使用的通道；如请求预览，附实绘图或标明来源的设计稿。公开投稿是用户另外发起的操作。

用户想知道如何开始，或需要可复制的生成提示词时，见 [开始使用与提示词](使用与提示词.md)。
